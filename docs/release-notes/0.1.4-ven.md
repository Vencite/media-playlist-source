# Media Playlist Source 0.1.4-ven

## Audio routing

- Route internal playlist decoder audio back through the Media Playlist Source
  parent so its mixer, mute, filters, and track routing remain authoritative.
- Prevent the internal decoder from contributing independently when a source is
  duplicated in the active scene or transition audio tree.
- These changes target the encoded-output and transition reports referenced
  below; OBS 32 runtime validation remains required before treating them as
  conclusively resolved.

## Compatibility

- Preserve seamless A/B playlist switching and local-video preload behavior.
- Vencite-maintained fork release.

This release addresses the reports in
[CodeYan01/media-playlist-source#56](https://github.com/CodeYan01/media-playlist-source/issues/56)
and
[CodeYan01/media-playlist-source#58](https://github.com/CodeYan01/media-playlist-source/issues/58).

OBS 32 recording and streaming scenarios remain a manual release validation
step; see [the regression checklist](../../tests/manual-regression.md).
