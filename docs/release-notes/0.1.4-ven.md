# Media Playlist Source 0.1.4-ven

This release focuses on production reliability while preserving the seamless playlist playback introduced in the Vencite fork.

## Highlights

- Fixes internal decoder audio routing so the parent Media Playlist Source remains authoritative for mixer gain, mute, filters, and OBS track routing.
- Preserves seamless A/B playlist switching with preloading for consecutive local video files.
- Keeps the fix for the short blank or transparent frame that could expose sources underneath the playlist between files.
- Runtime validation completed on Windows and macOS.

## Audio routing

Internal playlist decoder audio is now routed back through the Media Playlist Source parent instead of contributing independently to the OBS audio graph.

This prevents duplicated or incorrectly scaled audio when the playlist source appears more than once in an active scene or transition audio tree and ensures the parent source controls:

- mixer gain,
- mute state,
- filters,
- OBS audio track routing.

Upstream report [#58](https://github.com/CodeYan01/media-playlist-source/issues/58) was reproduced on `0.1.3-ven.1` on Windows and macOS and no longer reproduced on `0.1.4-ven` with reduced mixer gain or full mute during scene transitions.

Upstream report [#56](https://github.com/CodeYan01/media-playlist-source/issues/56) was not reproducible in the available environment, including on the previous fork version, so this release does not claim it as a runtime-verified fix.

## Playback compatibility

Automatic A -> B -> C playback and the previous blank or transparent-frame regression were manually verified on `0.1.4-ven`. Seamless A/B switching and local-video preload behavior remain intact after the audio-routing changes.

See the [manual regression checklist](../../tests/manual-regression.md) for the validated scenarios.
