# Media Playlist Source 0.2.1

A maintenance release for Studio Mode and playlist playback. Changes below are
relative to **0.2.0**.

## Fixes

- Playlist Queue and Playlist Control follow the scene instances on the live
  Program output, including private copies created by **Duplicate Scene** with
  **Edit Properties** enabled. Preview-only scene changes no longer select a
  different source in the following docks.
- During a Fade, the docks count distinct visible MPS instances on both sides.
  Follow-mode controls pause while Program has multiple matches and resume when
  the target becomes unique. Nested scenes, groups, and shared references are
  handled by the same Program lookup in both docks.
- Playlist Queue keeps its playlist context through a transient timing read
  failure and resumes timing on the next successful read.
- Restart and resume can recover when Stop cancels the first decoder switch.
  A standby decoder that OBS rejects as an active child is never committed.

## Installation and compatibility

Close OBS before installing the update. Use the macOS Universal PKG for Apple
Silicon or Intel, the Windows x64 installer or portable ZIP, or the Ubuntu
x86_64 package. The build targets OBS Studio 31.1.1.

## Known limitations and validation

- OBS controls the Audio Mixer categories. With **Edit Properties** enabled,
  the public Preview source can still be shown as **Preview** while its private
  Program copy provides the audio on output.
- Automated regression tests cover libobs scene identity, transition targets,
  private-source lifetime, and decoder lifecycle. The full OBS GUI and audio
  recording matrix is described in the [manual regression checklist](../../tests/manual-regression.md).
