# Media Playlist Source 0.2.0

A stable release of the Vencite fork, with live folder updates, external playlist control and improved playback reliability. Changes below are relative to **0.1.5-ven**.

## New features

- **Live folder monitoring**, optional per source: refresh folder contents without restarting the active clip, choose from five filename/date sorting modes and 2/5/10/30-second scan intervals, and optionally require stable file size and modification time across two scans.
- **obs-websocket telemetry:** read current media, playback state, speed, elapsed/remaining time and playlist timing with `GetPlaylistState`, and subscribe to `PlaylistStateChanged` events.
- **External playlist control:** browse entries with `GetPlaylistEntries`, choose one with `SelectPlaylistItem`, and change Shuffle/Loop with `SetPlaybackOptions`.
- **Shuffle reset behaviour:** preserve the current cycle by default or start a fresh shuffle when the source becomes active, with independent randomization per source.

## Dock improvements

- Simplified Playlist Queue and Playlist Control layouts, with an optional playback toolbar.
- Follow Program, Shuffle and Loop options in the docks' context menus.
- Playlist remaining time anchored at the bottom of Queue and hidden while Loop is enabled. Current-file timing remains visible.

## Fixes

- Corrected shuffle history after Restart First File and history-index wraparound.
- Prevented playlist settings updates from skipping the prepared next item.
- Improved folder identity handling and recovery when unavailable folders return.
- Preserved Previous navigation when the playing file has been removed from a monitored folder.
- Protected Properties and save reads during folder reconciliation.
- Used precise Windows file timestamps to detect same-size changes within one second.
- Avoided unnecessary copying and sorting on unchanged folder scans.

## Installation and compatibility

Close OBS before updating. Download the Windows x64 installer or portable ZIP, macOS Universal PKG (Intel and Apple Silicon), or Ubuntu x86_64 Debian package from this release's assets. Back up your scene collection before updating.

Existing source IDs and saved setting keys are preserved. Folder monitoring is off by default; existing playlists retain their shuffle cycle behaviour unless the new option is selected.

The build targets OBS Studio 31.1.1. The maintainer reports successful manual OBS testing on Windows and macOS; Linux manual OBS testing has not been confirmed for this release.

## Known limitations

- File-stability checks help avoid unfinished copies but cannot guarantee that a copy has completed.
- A blocked network filesystem operation can delay monitoring of other folders and OBS shutdown. NAS/SMB-specific validation is not separately confirmed.
- The Properties filename refreshes when the window is reopened.
- Selecting embedded audio or subtitle tracks is not supported.
- The API is available to external clients; a ready-made Companion module or preset is not included.

See the [README](../../README.md) and [WebSocket API reference](../playlist-telemetry.md) for setup and integration details.
