# Media Playlist Source 0.1.5-ven

## What's new

- Added the **Playlist Queue** OBS dock with Previous, Now Playing and Up Next information.
- Added playback progress, elapsed/remaining time, and safely obtained media duration information.
- Added the **Playlist Control** dock for browsing the configured playlist and starting a selected file or folder item.
- Added independent **Follow Program MPS** support for Queue and Control.
- Added Program-scene MPS indicators in the Queue source selector.
- Added MPS discovery through visible groups and nested scenes.
- Improved dock layout, responsive behavior, native OBS/Qt theme integration, icons, table alignment, and operator readability.

## Reliability

The C playback core remains authoritative. Dock metadata does not probe files or create extra decoders, and UI refreshes do not alter shuffle order. Copied snapshots and UUID-based source handling keep the Qt docks safe across OBS source lifetime changes.

## Validation

Validated with Windows/macOS/Linux CI and mixed codecs and containers, audio-only and video-only media, short files, changing resolution/FPS/VFR, multiple audio formats, corrupt-file recovery, looping/shuffle, scene switching, and Program/Preview and nested scene/group behavior.
