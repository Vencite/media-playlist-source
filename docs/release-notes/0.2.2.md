# Media Playlist Source 0.2.2

A maintenance build for OBS Studio 33. The build targets OBS Studio 31.1.1.

## Fixes

- OBS Studio 33's Plugin Manager displays the installed plugin version.
- The playlist docks follow the visible Program scene as soon as a transition
  finishes on video, even if OBS is still finishing its audio transition.
- Audio forwarded from the active decoder uses OBS's monotonic clock. This
  prevents a decoder switch or restart from reusing timestamps from a previous
  playback run and delaying audio on Program.
- Audio packets remain contiguous when the sample queue wraps. This avoids
  reading samples outside the queued packet.
- Leaving Program in a stop-on-hide mode no longer treats the decoder's stop
  as a natural clip end and advances the playlist a second time.

## Studio Mode audio monitoring

With **Duplicate Scene** and **Duplicate Sources** (called **Edit Properties**
in some OBS versions), OBS can play a private copy of an MPS source. OBS does
not copy the original source's monitoring setting when it creates that copy.
The public source's mixer row can still show **Preview**. Check Program audio
independently of the mixer row or local speakers.

To keep one mixer row and the original source's monitoring settings, enable
**Duplicate Scene** and disable **Duplicate Sources**. This shares the MPS
playback instance between Preview and Program while preserving the scene copy.
